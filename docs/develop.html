Human-gated

Development is incremental. One explicit Architect task at a time. No feature, game rule, module, or system is created “in advance.” No production code until the Architect approves the Gate B Phase 1 plan. After implementation and a validation report, the Architect must explicitly accept the slice before git commit and push.

This is not unattended autogen. Interactive, supervised sessions are the default. Proactive improvement ideas are welcome; implementing them requires approval.

Honest pre-alpha

Underground Kingdom is a dwarven colony sim — underground only — in pre-alpha on PC. It is not UnderKingdom. It is not The Ants: Underground Kingdom. There is no Steam link yet. Store and social channels are coming soon.

Volume World is the product direction (deep starter hall, live Z, cutaway cave). Remaining work is named on the progress page: 1-tall ladder/wall visuals, back-wall climb, cutover, art. We do not pretend those are done.
