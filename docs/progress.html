Progress over time

Dates come from the git log. Eras follow the Unity migration, then needs and production, then Volume World and 2.5D parity, then the Volume product slices. Remaining work is named. Nothing here is a store date.

Architect-accepted slices only. Grok Build implements; Colin accepts; then commit. Pre-alpha. Not released.

    Volume roadmap complete + large service split V2 Implemented

    Architect cancelled Volume roadmap G (gold kit / furniture / enemy-plant art). Color fallbacks stay valid. Volume product sequence is complete: V1–V5 + F. Then: Large service split V2 — structural extracts only (inspection HUD internals, tick runner vs HUD orchestrator, Agent Nulls + walk type, TaskReachability, Labor path/stands/station/structure, BuildingEgress, catalog/host/carver/chase/lift, overview V2).     • 6 Sep 2026Large service split V2 (UK-FEAT-LARGE-SERVICE-SPLIT-V2) — drops D1–D8 accepted.

  7. 8 September 2026

    Recipe unify, Modular forge, starter hall, dollhouse cutaway Implemented

    Chamber buildings share one resolve path (depth-1 structures vs shared W×H shells at depth 5). Forge gets a unique Modular masonry shell with sparse workshop props. New Game starter hall expands to a single-storey 55×7 right wing so Marketplace fits, and hostiles no longer spawn inside the hall. Shared shells and forge open the near face at z=0 for dollhouse cutaway visibility (floors stay).

    • 8 Sep 2026Volume recipe resolve unify V1 (UK-FEAT-VOLUME-RECIPE-RESOLVE-UNIFY-V1).
    • 8 Sep 2026Volume forge building recipe V1 — unique Modular shell + sparse interior.
    • 8 Sep 2026Starter hall expand V1 — 55×7 right wing for Marketplace; hall enemy exclude.
    • 8 Sep 2026Volume shell dollhouse cutaway — skip near-face block/trim at z=0 (floors stay).

  8. 10 September 2026

    Volume recipe visual editor V1 Implemented

    Each building type now has its own authored Volume recipe on disk, registered through a catalog so editing one chamber never rewrites another. A WYSIWYG editor assigns Modular sprites in a preview scene; play still falls back to the factory resolve path when no catalog is wired.

    • 10 Sep 2026Volume recipe visual editor V1 (UK-FEAT-VOLUME-RECIPE-VISUAL-EDITOR-V1) — unique authored recipe per type + catalog-first resolve.

  9. 11 September 2026

    Earth seamless UV + dual-density presentation Implemented

    Cutaway earth–earth joins now sample the seamless plate by world XY the same way 2D crops do, so side-by-side cave walls no longer show a hard texture jump. Presentation also keeps shipped 64-density occupancy looking identical while accepting per-asset 128 remakes at the same tile fill — forward art lock is 128 PPT without a global half-size flip.

    • 11 Sep 2026Volume earth −Z seamless UV V1 (UK-FEAT-VOLUME-EARTH-SEAMLESS-UV-V1) — cutaway earth UVs match 2D period sampling.
    • 11 Sep 2026Presentation dual-density occupancy PPU V1 (UK-FEAT-PRESENTATION-DUAL-DENSITY-PPU-V1) — shipped 64 look frozen; 128 drop-in ready.

    Remaining (honest)

    • Done Volume product roadmap (V1–V5 + F). G cancelled — not remaining work.
    • Approved Ladder path fix V1 — coding plan exists (26 Aug 2026), no accept commit. Volume ladders may stay broken; V5 free-climb is the upstairs path.

    Fresh product slices start only when the Architect tasks them. Color kit fallbacks remain valid until an explicit ASSET_* task. Production art remakes to 128 PPT land one asset at a time.
