A3 Sim tick (pause-respecting): while awake and Attention > 0, drain −1 Attention per 10.0 sim-seconds (same accumulator style as Food).
A4 While sleeping, Attention does not drain; restore applies instead (see B).
A5 While Attention == 0, do not drain further; apply move penalty only (no HP, no work-speed penalty, no death from Attention).
A6 Only colonists — no Attention on enemies, moles, or buildings.
A7 Save/load: persist Attention; clamp [0, 100]; missing field on old saves → 100.
B. Sleep behavior (Labor + Agents)
B1 Seek threshold: when Attention ≤ 50, sleep is allowed, cooldown ≤ 0, and dwarf is not already on a Sleep task → attempt start sleep seek (mirror Eat threshold style).
B2 Claim priority: Eat → Sleep → existing work claim order (BUILD → …). Sleep must not steal work while Food ≤ 50 and eat is available/attempted first.
B3 Site priority (search order):
1) Completed Living Quarters within range with free sleep capacity, path-reachable, prefer closer (Coding may pick nearest-by-Chebyshev then path check).
2) Else completed Tents same rules.
3) Else sleep on current tile (no walk).
B4 Range: Chebyshev max(|dx|, |dy|) ≤ 100 from dwarf position to a tile of the candidate building footprint (or building origin — Coding plan picks one consistent rule; recommend any footprint tile within range counts the building in range).
B5 Path-reachable: only select a building if a path exists to a walkable tile in its footprint. If none pathable in range (or all full), fall back to current-tile sleep.
B6 Capacity: concurrent sleepers per building ≤ level DwarfCapacity. No permanent assignment. Free slot when dwarf wakes, is cancelled, dies, or leaves sleep. Demolished/missing building → sleeper treats as interrupt (wake; Coding: apply 60 s cooldown only if interrupt maps to damage/move; for demolish, recommend wake + 60 s to avoid thrash — if pure edge case, wake + re-seek on next cycle is acceptable; prefer wake without Don’t-Sleep, and apply cooldown only for Move / combat damage per Architect locks).
B7 Stand target: any walkable tile in building footprint (first successful path target). Multiple sleepers may share footprint tiles if path/stacking allows; capacity is count-based, not unique-tile-based.
B8 Restore rates (while sleeping on site):
• Free world tile: +1 Attention / 2.0 sim-seconds
• Tent: +1 Attention / 1.5 sim-seconds
• Living Quarters: +1 Attention / 1.0 sim-seconds
Clamp to 100; overfill discarded.
B9 Wake when Attention reaches 100; complete Sleep task; resume normal labor on later idle cycles.
B10 While sleeping: immobile for work (no dig/build/etc.), no auto-attack, Attention restores, still vulnerable to combat.
B11 Combat damage while sleeping → immediate wake + start 60 s sleep-seek cooldown (sim-time, pause-respecting).
B12 Player Move while seeking or sleeping → cancel sleep/seek + 60 s cooldown.
B13 Don’t Sleep toggle true → cancel in-progress sleep/seek if any; no 60 s cooldown; while true, never start sleep seek; when toggled false → may seek immediately if Attention ≤ 50.
B14 Cooldown: after Move cancel or combat wake, dwarf will not auto-seek sleep for 60.0 sim-seconds. Cooldown ticks only while sim runs (pause-respecting).
B15 Sleep task: new TaskType (e.g. Sleep) or equivalent Labor-owned sleep state that shows on Inspect task line; Coding plan chooses Tasks vs pure Labor blackboard as long as cancel/Move/damage integration is clean and claim priority works. Prefer a real task if Eat is a task (consistency).
B16 Save/load: persist Don’t-Sleep flag, remaining sleep cooldown (seconds), and enough state to resume or safely clear mid-sleep (if mid-sleep on load: either resume sleep at same site type/rates if building still valid, or clear Sleep task and keep Attention — Coding plan must pick one deterministic rule; recommend: if saved as sleeping and building still has capacity, resume; else awake with current Attention, cooldown 0 unless saved cooldown remains).
